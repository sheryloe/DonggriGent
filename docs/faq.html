자주 묻는 질문(FAQ)

로그인, MCP 연결, 브라우저 모드, 호환성, 장애 대응을 중심으로 자주 발생하는 질문을 정리했습니다.

로그인/CAPTCHA

Q. CAPTCHA를 자동으로 우회하나요?

A. 아니요. KGentool은 우회 기능을 제공하지 않습니다. 검증 화면은 사용자가 직접 처리해야 합니다.

Q. SSO 로그인 창이 막힙니다.

A. 제어 센터에서 인증 팝업 허용을 확인하고, 필요하면 백엔드를 chrome-cdp로 전환하세요.

Q. 기존 Chrome 프로필 모드 사용 시 실패합니다.

A. 일반 Chrome이 같은 프로필을 사용 중이면 충돌할 수 있습니다. 일반 Chrome 종료 후 다시 시도하세요.

MCP/도구

Q. 도구 목록에 kgentool_*가 보이지 않습니다.

A. MCP 등록 커맨드 경로와 서버명을 확인한 뒤 CLI를 재시작하고 mcp list를 재확인하세요.

Q. 기존 agentify_* 자동화가 깨지나요?

A. v1에서는 호환 alias가 유지됩니다. 다만 신규 개발은 kgentool_* 기준으로 전환하세요.

워크플로/런타임

Q. tab_busy 오류가 발생합니다.

A. 동일 탭에서 이미 active query가 실행 중입니다. 완료/중지 후 재시도하거나 key를 분리하세요.

Q. 상태 데이터는 어디에 저장되나요?

A. 기본 경로는 ~/.kgentool/ 입니다.

트러블슈팅 체크리스트

  1. 앱이 실행 중인지 확인 (npm run start)
  2. 벤더 로그인 상태와 입력창 ready 여부 확인
  3. MCP 등록 경로와 서버명 확인
  4. 필요 시 브라우저 백엔드 전환
  5. kgentool_status로 active/runtime 상태 확인
장애 보고 시에는 사용한 key, vendor, backend, 호출 도구 이름을 함께 남기면 분석 속도가 빨라집니다.
