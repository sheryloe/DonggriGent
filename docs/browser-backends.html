브라우저 백엔드 선택

KGentool은 electron과 chrome-cdp 두 모드를 지원합니다. 로그인/SSO 안정성과 운영 편의성을 기준으로 선택하세요.

Electron (기본)

  • 앱 내장 창으로 바로 실행
  • 온보딩 속도가 빠르고 설정이 단순
  • 일반 사용/로컬 테스트에 적합
초기 도입이나 데모 환경에서는 Electron이 가장 빠릅니다.

Chrome CDP

  • 실제 Chrome 계열 브라우저 세션 사용
  • Google/Microsoft/Apple SSO 안정성이 상대적으로 높음
  • 기존 프로필 재사용 또는 격리 프로필 선택 가능
SSO/팝업 문제가 반복되면 Chrome CDP 전환을 권장합니다.

권장 선택 기준

상황 권장 백엔드 이유
빠른 시작/개인 테스트 electron 구성 단순, 시작 시간 짧음
SSO 로그인 이슈 반복 chrome-cdp 실제 브라우저 흐름에 가까워 안정적
기존 Chrome 세션 재사용 필요 chrome-cdp + existing profile 일상 프로필 문맥 공유

전환 절차

  1. 제어 센터에서 Browser backend 변경
  2. 필요 시 Chrome profile mode 설정
  3. 저장 후 앱 재시작

운영 주의사항

  • CAPTCHA 우회는 지원하지 않음(수동 처리)
  • 기존 프로필 모드 사용 시 일반 Chrome과 충돌 가능
  • 팝업 차단 정책은 인증 흐름에 직접 영향
기존 Chrome 프로필을 쓸 때는 일반 Chrome을 먼저 종료하는 운영 규칙을 권장합니다.
