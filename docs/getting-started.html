KGentool 5분 시작

처음 설치하는 사용자를 기준으로, 최소 명령과 최소 선택으로 바로 작동하는 상태까지 안내합니다.

설치 상세 보기 MCP 연결 보기

1) 저장소 준비

git clone https://github.com/agentify-sh/desktop.git
cd desktop

2) 빠른 시작 스크립트 실행

./scripts/quickstart.sh

이 스크립트는 의존성 설치, MCP 등록(선택), 앱 실행까지 한 번에 처리합니다.

3) 제어 센터에서 기본 탭 열기

  • 기본 탭 열기 버튼 클릭
  • 원하는 벤더 계정으로 로그인
  • 필요하면 Browser backend를 chrome-cdp로 변경

4) MCP 등록(수동 필요 시)

codex mcp add kgentool-desktop -- node /ABS/PATH/TO/desktop/mcp-server.mjs

다른 클라이언트는 MCP 연결 문서 참고.

5) 첫 요청 실행

{
  "tool": "kgentool_query",
  "arguments": {
    "key": "quickstart",
    "prompt": "현재 저장소 구조를 5줄로 요약해줘."
  }
}
같은 key를 재사용하면 같은 탭 세션 문맥이 유지됩니다.

빠른 검증 체크리스트

  • 제어 센터가 열렸는가
  • 벤더 로그인 후 프롬프트 입력 가능 상태인가
  • MCP 클라이언트에서 kgentool_query 호출이 성공하는가
  • kgentool_status에 tab/runtime 정보가 보이는가
