MCP 연결 가이드

KGentool 서버명은 kgentool-desktop이며, 기본 MCP 엔트리는 node mcp-server.mjs 입니다.

Codex

codex mcp add kgentool-desktop -- node /ABS/PATH/TO/desktop/mcp-server.mjs
codex mcp list

Claude Code

claude mcp add --transport stdio kgentool-desktop -- node /ABS/PATH/TO/desktop/mcp-server.mjs
claude mcp list

OpenCode

quickstart 스크립트의 --client opencode 또는 --client all 사용을 권장합니다.

./scripts/quickstart.sh --client opencode

등록 후 최소 검증

  1. kgentool_tabs 호출로 연결 확인
  2. kgentool_status 호출로 상태 확인
  3. kgentool_query로 짧은 질의 1회 실행
{
  "tool": "kgentool_query",
  "arguments": {
    "key": "mcp-check",
    "prompt": "연결 점검용 응답 한 줄만 반환해줘."
  }
}

주요 도구(신규)

  • kgentool_query
  • kgentool_status
  • kgentool_tabs
  • kgentool_save_artifacts
  • kgentool_workflow_run

호환 도구(기존)

기존 자동화가 있으면 agentify_* alias를 그대로 사용할 수 있습니다.

신규 스크립트/프롬프트 작성 시에는 kgentool_* 네임스페이스를 권장합니다.

문제 해결

  • 도구가 보이지 않으면: CLI 재시작 후 mcp list 재확인
  • 응답이 지연되면: 앱 실행 여부, 로그인 상태, activeQuery 확인
  • 로그인/검증 화면이면: 브라우저 창에서 수동 처리 후 재시도

상세 예외 상황은 FAQ 문서 참고.
