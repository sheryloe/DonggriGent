MCP 등록 가이드

누구를 위한 문서: 앱 실행은 완료했고 Codex/Claude에 MCP를 연결하려는 사용자

완료 기준: `kgentool_tabs`, `kgentool_status`, `kgentool_workflow_run` 호출 가능

사전 확인

cd ~/DonggriGent
npm run start

앱이 먼저 실행 중이어야 MCP 호출이 정상 동작합니다.

`~/.kgentool/`에는 로컬 인증/런타임 정보가 저장됩니다. 공유/업로드하지 마세요.

절대 경로 확인

cd ~/DonggriGent
pwd
# 예: /home/<USER>/DonggriGent

`mcp-server.mjs`는 위 경로 기준으로 `/home/$USER/DonggriGent/mcp-server.mjs`를 사용합니다.

Codex 등록

codex mcp add kgentool-desktop -- node /home/$USER/DonggriGent/mcp-server.mjs
codex mcp list

Claude Code 등록

claude mcp add --transport stdio kgentool-desktop -- node /home/$USER/DonggriGent/mcp-server.mjs
claude mcp list

등록 후 검증 호출

아래 JSON은 터미널 명령이 아니라 MCP 도구 호출 예시입니다.

{
  "tool": "kgentool_tabs",
  "arguments": {}
}
{
  "tool": "kgentool_status",
  "arguments": {
    "key": "mcp-check"
  }
}
{
  "tool": "kgentool_workflow_run",
  "arguments": {
    "workflowName": "mcp_extension_ko",
    "prompt": "현재 MCP 도구 세트에서 확장 우선순위와 검증 계획을 한국어로 정리해줘."
  }
}

레거시/선택 사항

  • 기본 사용: `kgentool_*`
  • 기존 자동화 호환이 필요할 때만: `agentify_*`
