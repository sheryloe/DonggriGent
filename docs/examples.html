복붙해서 바로 쓰는 실전 예시

아래 예시는 실제 운영 흐름 기준으로 정리했습니다. 각 샘플마다 문제 상황 → JSON 호출 → 예상 결과 → 다음 액션 순서로 바로 실행할 수 있습니다.

첫 예시 바로 복붙 5분 시작 먼저 보기
처음이면 이 3개부터
  1. 문서 링크 회귀 점검 (`kgentool_query`)
  2. 문서 운영 개선안 자동 생성 (`mcp_extension_ko`)
  3. 배포 직전 상태 확인 + 산출물 저장
아래 JSON은 터미널 명령이 아니라 MCP 도구 호출 예시입니다.

예시가 쓰이는 운영 맥락

이 문서의 예시는 링크 점검, 구조 정리, 배포 직전 확인이라는 실제 작업 흐름을 전제로 구성했습니다. 아래 콜라주에서 어떤 맥락에서 예시가 쓰이는지 먼저 훑고 바로 실행하면 됩니다.

처음 사용하면 이 예시부터 복붙하세요. 가장 실패 확률이 낮은 흐름만 먼저 배치했습니다.

예시 1) 링크/경로 회귀 탐지

문제: 배포 전 docs 링크 깨짐을 한 번에 잡고 싶을 때

{
  "tool": "kgentool_query",
  "arguments": {
    "key": "gh-pages:link-audit",
    "model": "chatgpt",
    "contextPaths": [
      "docs/index.html",
      "docs/getting-started.html",
      "docs/mcp-setup.html",
      "docs/workflows.html",
      "docs/architecture.html"
    ],
    "promptPrefix": "GitHub Pages 배포 전 점검 모드로 동작한다.",
    "prompt": "깨진 내부 링크, 잘못된 경로, 존재하지 않는 앵커를 파일명:줄번호 형식으로 제시하고 교체안까지 작성해줘.",
    "maxContextInlineFiles": 20,
    "maxContextChars": 18000
  }
}

예상 결과: 수정 대상 파일/줄번호 + 교체 문자열 제안

다음 액션: 수정 후 동일 `key`로 재실행해 회귀 재검증

예시 2) 문서 개선안 자동 생성

문제: 문서 규약/동선/용어 통합안을 빠르게 만들고 싶을 때

{
  "tool": "kgentool_workflow_run",
  "arguments": {
    "workflowName": "mcp_extension_ko",
    "prompt": "현재 GitHub Pages 문서 운영 규약 기준으로 링크 정책, 도구 명명 규칙, Troubleshooting 동선을 통합한 개선안 1개를 만들어줘. docs/index.html, docs/workflows.html, docs/mcp-setup.html 중심으로 체크리스트와 검증 순서 포함."
  }
}

예상 결과: `plan → implementation → review` 3단계 산출물

다음 액션: `outputs.review` 기준으로 반영/검증/롤백 체크리스트 작성

예시 3) 배포 직전 상태 점검

문제: 로그인 차단/응답 지연 상태로 배포 직전에 실패할 때

{
  "tool": "kgentool_status",
  "arguments": {
    "key": "gh-pages:publish",
    "model": "chatgpt"
  }
}
{
  "tool": "kgentool_save_artifacts",
  "arguments": {
    "key": "gh-pages:publish",
    "mode": "files",
    "maxFiles": 8
  }
}

예상 결과: `blocked` 상태 확인 + 저장된 아티팩트 목록 확보

다음 액션: PR에 아티팩트 경로 첨부 후 배포 진행

상황별 확장 리스트

처음 시작 리팩터링 보안 점검 MCP 확장 워치 폴더 운영 점검
  • 리팩터링 자동화: `cpp_refactor_ko`
  • 보안 하드닝: `vendor_hardening_ko`
  • 도구 계약 확장: `mcp_extension_ko`
  • 파일 인입 파이프라인: `agentify_add_watch_folder`
  • 운영 상태 복구: `kgentool_status`, `agentify_ensure_ready`

실행 결과 체크리스트

  • 응답에 `tabId`/`meta`/`packedContextSummary`가 포함됐는지 확인
  • 워크플로 응답에 `steps`와 `outputs.review`가 채워졌는지 확인
  • `blocked=true`면 로그인/팝업 완료 후 재시도
  • 아티팩트 저장 후 파일 경로를 PR/노트에 기록
  • 신규 작업은 `*_ko` 우선, 레거시는 호환이 필요할 때만 사용
무엇을 실행할지 애매하면 `mcp_extension_ko`부터 실행해 현재 상태 진단 + 개선안을 동시에 받으세요.
