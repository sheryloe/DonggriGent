팀 공유용 KGentool 소개 슬라이드

이 페이지는 발표용 슬라이드 원본을 빠르게 훑어볼 수 있는 웹 버전입니다. 정식 원본은 Markdown 한 파일로 관리하며, Wiki와 GitHub에서도 그대로 읽을 수 있습니다.

슬라이드 원본(Markdown) 아키텍처 인포그래픽 Wiki Home

슬라이드 1. 문제 정의

웹 로그인 세션과 CLI 실행 흐름이 분리되어 반복 전환 비용이 발생합니다. 프로젝트 컨텍스트와 산출물 루프도 매번 초기화됩니다.

슬라이드 2. 가치 제안

MCP + 로컬 브라우저 세션 + 워크플로를 한 제품으로 통합해 운영 시간을 줄입니다. 한국어 우선 문서와 런타임 구조를 제공합니다.

슬라이드 3. 아키텍처

UI/Electron Shell은 브라우저 제어를 담당하고, C++ Core는 상태/정책/워크플로를 담당합니다.

슬라이드 4. 설치와 실행

quickstart.sh 기준 5분 안에 실행하고, 필요 시 수동 설치와 C++ 코어 빌드 경로로 확장합니다.

슬라이드 5. MCP 연동

Codex/Claude/OpenCode를 모두 지원하고, kgentool_*와 agentify_* alias를 함께 운영합니다.

슬라이드 6. 워크플로 운영

.kgentool/workflows.toml과 .codex/agents/ 정의를 공유해 supervisor-executor-reviewer 체인을 표준화합니다.

슬라이드 7. 차별점

한국어 문서 체계, 로컬 상태 루트, 벤더 프로파일 레지스트리, 탭 키 재사용 정책을 기반으로 운영 난이도를 낮춥니다.

슬라이드 8. FAQ/리스크

CAPTCHA 자동 우회는 지원하지 않으며 사람 개입을 전제로 합니다. SSO 이슈는 chrome-cdp 모드가 기본 대응책입니다.
