워크플로 운영 가이드

키 규칙, 탭 재사용, 산출물 루프, 워치 폴더, 멀티 에이전트 실행을 운영 가능한 표준으로 정리합니다.

탭 키 운영 규칙

  • 프로젝트별 고정 key 사용: repo-name, billing-bot 등
  • 같은 key는 같은 탭/세션 재사용
  • 팀 운영 시 key 네이밍 규칙 문서화 권장

기본 호출 패턴

{
  "tool": "kgentool_query",
  "arguments": {
    "key": "repo-audit",
    "prompt": "현재 변경사항 리스크를 우선순위로 정리해줘."
  }
}

산출물 루프

  1. kgentool_query 실행
  2. kgentool_save_artifacts 호출
  3. 반환 경로를 다음 호출 attachments에 재사용
{
  "tool": "kgentool_save_artifacts",
  "arguments": { "key": "sprite-lab", "mode": "images", "maxImages": 4 }
}

워치 폴더 루프

  1. 워치 폴더 등록
  2. 로컬 파일 드롭
  3. 스캔 실행 후 인덱싱 결과 확인
{
  "tool": "agentify_add_watch_folder",
  "arguments": { "name": "inbox", "folderPath": "/ABS/PATH/INBOX" }
}

workflow.run 체인

현재 기본 워크플로:

  • cpp_refactor: supervisor → cpp-pro-kg → reviewer-kg
  • vendor_hardening: supervisor → vendor-profile-kg → reviewer-kg
  • mcp_extension: supervisor → mcp-contract-kg → reviewer-kg
{
  "tool": "kgentool_workflow_run",
  "arguments": {
    "workflowName": "vendor_hardening",
    "prompt": "claude selector 변화에 대한 회귀 위험 점검"
  }
}

운영 체크포인트

  • activeQuery 충돌 시 tab_busy 응답 처리
  • timeout/stop 정책을 작업 성격에 맞게 조정
  • watch folder 경로는 절대 경로만 허용

장애 대응 기준

  • 로그인 문제: 브라우저 백엔드 전환 검토
  • 요청 지연: status/runtime에서 active 쿼리 확인
  • 도구 표준화: 신규는 kgentool_* 사용
호환성 때문에 agentify_*는 유지되지만 운영 표준은 kgentool_*로 통일하는 것이 좋습니다.
