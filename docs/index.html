모르는 사람도 바로 쓰는 DonggriGent

이 페이지는 설치부터 MCP 등록, 첫 워크플로 실행까지 한 번에 안내하는 시작점입니다. 복붙 가능한 명령과 JSON 예시를 그대로 제공하고, 기본 워크플로는 *_ko를 권장합니다.

권장 진입: 처음 사용하는 경우 빠른 시작부터 시작하고, 설치 문서는 필요할 때만 확인하세요.

비전공자용 4단계 시작

  • 1) 설치: `npm ci` + `npm run start`
  • 2) MCP 연결: Codex 또는 Claude Code에 도구 등록
  • 3) 첫 질의: `kgentool_query`로 오늘 목표 3개 요청
  • 4) 결과 저장: `kgentool_save_artifacts`로 다음 작업에 재사용
목표는 먼저 완벽이 아니라, 5분 안에 첫 호출 성공입니다.

이렇게 쓰면 잘 맞는 조합

  • 기획팀: 요구사항 정리를 `key` 기준으로 표준화
  • 개발팀: 브라우저 세션 유지 작업 + 리뷰 흐름 합치기
  • PM: 산출물 저장 루틴으로 보고서 작성 시간 단축
반복성 기반 운영이 결국 운영 효율을 만듭니다.

도구 호출 예시

아래 JSON은 터미널 명령이 아니라 MCP 클라이언트 도구 호출 예시입니다.

kgentool_query

{
  "tool": "kgentool_query",
  "arguments": {
    "key": "quickstart",
    "prompt": "현재 저장소에서 오늘 바로 할 작업 3개를 한국어로 정리해줘."
  }
}

kgentool_workflow_run

{
  "tool": "kgentool_workflow_run",
  "arguments": {
    "workflowName": "cpp_refactor_ko",
    "prompt": "C++ 리팩터링 우선순위와 검증 순서를 한국어로 제안해줘."
  }
}
신규 도입 시 문서/운영 모두 `*_ko`를 기본 추천으로 사용합니다.

문서 경로
