설치/실행 가이드

운영 환경에서 반복 실행 가능한 형태로, 설치/실행/상태 디렉터리/코어 빌드까지 한 번에 정리합니다.

요구사항

  • Node.js 20 이상 (권장 22)
  • npm
  • GUI 환경(Electron 창 실행 가능)
  • 선택: C++ 코어 빌드를 위한 CMake + C++20 컴파일러

기본 경로

  • 상태 루트: ~/.kgentool/
  • 워크플로: .kgentool/workflows.toml
  • Codex 에이전트: .codex/agents/
  • MCP 서버 엔트리: mcp-server.mjs

권장 설치(quickstart)

git clone https://github.com/agentify-sh/desktop.git
cd desktop
./scripts/quickstart.sh

주요 옵션:

./scripts/quickstart.sh --foreground
./scripts/quickstart.sh --show-tabs
./scripts/quickstart.sh --client codex
./scripts/quickstart.sh --client all

수동 설치

npm ci
npm run start

의존성 락 문제 시:

npm install

C++ 코어 빌드(선택)

npm run core:build
npm run core:test
현재 저장소는 C++ 코어 skeleton 단계이며, 런타임 일부는 JS fallback으로 동작합니다.

환경 변수(주요)

변수 의미
KGENTOOL_STATE_DIR상태 디렉터리 오버라이드
KGENTOOL_SHOW_TABS새 탭 기본 표시 여부
KGENTOOL_BROWSER_BACKENDelectron / chrome-cdp
KGENTOOL_CHROME_BINChrome 실행 파일 경로 지정
KGENTOOL_CORE_BINC++ 코어 바이너리 경로 지정

운영 체크

  • npm run test로 기본 테스트 상태 확인
  • 브라우저 로그인 시 팝업 차단 여부 확인
  • 상태 디렉터리 용량과 산출물 정리 주기 설정
  • 팀 사용 시 탭 키 네이밍 규칙 사전 합의
SSO 이슈가 있으면 브라우저 백엔드를 chrome-cdp로 전환하는 것이 일반적으로 안정적입니다.
