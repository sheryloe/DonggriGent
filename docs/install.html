설치 가이드

누구를 위한 문서: WSL 환경에서 처음부터 설치/실행까지 완료하려는 사용자

완료 기준: `npm run start` 실행 + `npm test` 통과 + MCP 등록 준비 완료

사전 요구사항

  • WSL2 Ubuntu
  • Node.js 22, npm 10+
  • git, build-essential
sudo apt update
sudo apt install -y curl git build-essential ca-certificates gnupg
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://deb.nodesource.com/gpgkey/nodesource-repo.gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/nodesource.gpg
echo "deb [signed-by=/etc/apt/keyrings/nodesource.gpg] https://deb.nodesource.com/node_22.x nodistro main" | sudo tee /etc/apt/sources.list.d/nodesource.list >/dev/null
sudo apt update
sudo apt install -y nodejs
node -v
npm -v

프로젝트 설치

cd ~
git clone https://github.com/sheryloe/DonggriGent.git
cd DonggriGent
npm ci

앱 실행

npm run start
PowerShell에서 `./scripts/quickstart.sh`는 바로 실행되지 않을 수 있습니다. WSL 또는 Git Bash를 사용하세요.

검증

cd ~/DonggriGent
npm test
npm run docs:check

테스트가 통과하면 MCP 등록으로 넘어갑니다.

MCP 등록 예고

cd ~/DonggriGent
codex mcp add kgentool-desktop -- node /home/$USER/DonggriGent/mcp-server.mjs
claude mcp add --transport stdio kgentool-desktop -- node /home/$USER/DonggriGent/mcp-server.mjs

상세 등록/검증은 MCP 등록 문서에서 진행하세요.

워크플로 실행 예시

아래는 터미널 명령이 아니라 MCP 도구 호출 예시입니다.

{
  "tool": "kgentool_workflow_run",
  "arguments": {
    "workflowName": "cpp_refactor_ko",
    "prompt": "현재 레포 기준으로 C++ 리팩터링 우선순위를 한국어로 정리해줘."
  }
}
신규 운영은 `*_ko` 워크플로를 기본으로 권장합니다.
